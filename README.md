# AI Mechanism Deep Dives - Week 12

This repo contains my Week 12 paired knowledge-gap research artifacts: daily questions, morning-call sharpening notes, explainers, public threads, source lists, signoffs, and grounding updates back into Week 10/11 portfolio work.

## Structure

- pair_DAY_1/ .. pair_DAY_5/ (daily deliverables)
- synthesis.md
- canonical_list.md
- portfolio_update.md
- ENV_SETUP.md

## Daily Folder Contents

- question.md
- morning_call_summary.md
- explainer.md
- thread.md

## How To Use

1) Each morning, fill question.md and morning_call_summary.md.
2) During the day, draft explainer.md and thread.md.
3) After the evening call, update evening_call_summary.md, signoff.md, and grounding_commit.md.
4) Add sources.md with two canonical sources and one tool or pattern.
5) At week end, complete synthesis.md, canonical_list.md, portfolio_update.md.
