- What I understand now that I did not before:

I understand now that an evaluation number is only meaningful when its denominator is honest. If a model abstains or returns unparseable output, answered-case accuracy is conditional on the model deciding to answer, so it is trustworthy only when coverage is reported and abstentions are checked by slice. If abstentions cluster on harder task types, conditional accuracy is biased and full-set reliability should treat abstention as a failure mode or separate outcome. For Amir's question, raw agreement and kappa answer different questions: raw agreement says how often the two labeling passes matched, while Cohen's kappa asks how much agreement remains after expected chance agreement. Because kappa can look deceptively low under extreme prevalence, it should be interpreted with base rates, contingency tables, and a prevalence-robust companion metric such as Gwet's AC1 or PABAK. The most important reporting correction is terminology: Amir's same-rater, 24-hour-gap protocol measures intra-rater reliability, not true inter-rater agreement, which narrows the claim from "independent evaluators agree" to "one evaluator was mostly consistent over time."
