Environment Setup (Markdown-only)

This repo contains only Markdown files. No runtime environment is required.

Recommended

- Git installed and configured.
- VS Code with a Markdown preview extension (optional).
- A clean publishing workflow for blogs and threads.

Conventions

- One daily folder per day: pair_DAY_1 .. pair_DAY_5.
- Keep filenames and headings consistent for easy review.
- Cite canonical sources with direct links in sources.md.
